# Fiber Install Log

i need an android app to document b2b fiber optic instalations. my app will have 4 main components: operations at the client (chose CPE, SFP installed or not, MediaConvertor installed or not, Terminal Box instaled or not, speed test (depending on the services installed), installed fiber optic cable with design on map, splicing on splice closures with splice location and ODF port and switch port at the site
